# Iterate — UI Design System

## Visual direction
Use the supplied Night Life visual reference for a dark, high-contrast, editorial atmosphere. Use the supplied Synaptix dashboard reference for application composition: compact left navigation, top utility bar, modular content panels, concise metrics, and generous content hierarchy.

Combine both references rather than copying either:
- Full viewport atmospheric purple/blue background outside the application shell.
- Near-black plum application surface with subtle glass transparency.
- Ambient purple and blue radial lighting, restrained magenta accents.
- White/lavender typography and readable muted secondary text.
- Thin translucent borders, restrained glow and soft shadows.
- Premium, clean dashboard; avoid excessive neon and clutter.

## Main dashboard
- Left navigation with brand, workspace links, recent projects, settings and local workspace identity.
- Top bar with breadcrumbs, project search, notifications placeholder and profile affordance.
- Welcome headline and new iteration action.
- Large idea capture panel.
- Four compact overview metrics.
- Recent projects panel and workflow explainer panel.

## Workspace pages
- My Projects: search, sorting affordance, responsive project cards.
- New Iteration: focused idea capture.
- Prompt Studio: generated prompt preview and quality review (subsequent milestone).
- AI Providers: provider connection status and safe key management (subsequent milestone).
- Settings: local data, privacy, backup and preferences.

## Responsive behavior
Desktop: persistent sidebar and multi-column cards.
Narrow screens: collapsible sidebar, stacked content, compact toolbar and touch-sized controls.

## Motion and accessibility
- Restrained hover and transition effects.
- Respect prefers-reduced-motion.
- Visible focus styles should be included in interactive controls as components mature.
- Ensure contrast remains readable over ambient gradients.
